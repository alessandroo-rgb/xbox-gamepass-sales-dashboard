# 🎮 Xbox Game Pass Sales Dashboard

## Sobre o Projeto

Dashboard de vendas desenvolvido durante o bootcamp Santander - Excel com IA, em parceria com a DIO.

O projeto teve como objetivo transformar dados de vendas do Xbox Game Pass em informações visuais para análise do desempenho comercial das assinaturas.

Foram utilizadas técnicas de ETL e tratamento de dados, além de tabelas dinâmicas, gráficos, segmentação de dados e elementos visuais personalizados no Microsoft Excel.

## Objetivos

- Analisar a receita das assinaturas Xbox Game Pass.
- Comparar o desempenho dos planos Core, Standard e Ultimate.
- Analisar a receita dos produtos EA Play e Minecraft Season Pass.
- Avaliar o ticket médio das vendas.
- Comparar o desempenho por tipo de assinatura e renovação automática.

## Principais Indicadores

- EA Play Revenue
- Minecraft Revenue
- Total Revenue
- Average Ticket

## Principais Análises

- Revenue by Plan
- Revenue by Subscription Type
- Revenue by Auto-Renewal

## 🛠️ Ferramentas

- Microsoft Excel
- Power Query
- Tabelas Dinâmicas
- Gráficos Dinâmicos
- Segmentação de Dados
- ETL e tratamento de dados
